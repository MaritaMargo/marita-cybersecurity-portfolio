# Lab 01 — Enterprise Network Security

**Course:** CyberStart Network Security Module  
**Tool:** Cisco Packet Tracer  
**Completed:** April 2026

---

## Scenario

A company relocating to a new office across two buildings 
needed a professionally designed, secure, and redundant 
enterprise network. Built from a realistic business 
scenario brief.

---

## What Was Built

- 2 buildings, 4 floor switches, 2 core switches
- 8 department PCs across 6 VLANs
- 4 servers — DNS/DHCP, HTTP, NTP, FTP
- Full security hardening

---

## Skills Demonstrated

`VLAN` `ACL` `STP` `Port Security` `SSH` 
`DHCP Snooping` `Static Routing` `Cisco IOS`
