# CyberStart — Network Security

**Program:** CyberStart Nordic-Baltic Cybersecurity Training Program  
**Co-funded by:** European Union / Interreg Central Baltic Programme  
**Organizer:** RigaTechGirls / ProxyLab  
**Duration:** March–May 2026  
**Level:** Entry-level / Career transition

---

## Overview

CyberStart is a Nordic-Baltic cybersecurity upskilling program 
addressing the underrepresentation of women in the cybersecurity 
workforce. The program provides 96 hours of training across 8 modules, 
combining theory with hands-on practical labs.

---

## Course Modules

1. Intro to Cybersecurity & Digital Fundamentals
2. **Network Security** ← this module
3. Cryptography, Authentication & IAM
4. Application & Web Security
5. Security Operations & Incident Response
6. Security Governance, Risk & Compliance (GRC)
7. Attacker Mindset & Ethical Testing
8. Careers & Cybersecurity Entrepreneurship

---

## Key Skills Developed

- Enterprise network design and segmentation (VLANs)
- Cisco IOS configuration and CLI
- Network security hardening (ACL, Port Security, SSH)
- Switching protocols (STP, Rapid PVST+, BPDU Guard)
- DHCP Snooping and ARP protection
- Static routing and inter-VLAN routing
- Network redundancy and failover design
- Security documentation and verification testing

---

## Practical Components

- Hands-on Cisco Packet Tracer lab simulations
- Realistic business scenario-based assignments
- Network topology design from requirements
- Security policy implementation and testing

---

## Course Project

**Home Lab 1 — Enterprise Network Security** — a fully simulated 
enterprise network across two buildings, designed from a realistic 
business brief. Includes VLAN segmentation, ACL policies, redundancy, 
and full security hardening using Cisco Packet Tracer.
