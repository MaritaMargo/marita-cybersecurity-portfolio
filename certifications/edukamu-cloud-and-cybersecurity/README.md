### Overview
Completed a 6-course, 12 ECTS microdegree developed by Microsoft and industry partners (CyberCoach, Atea, Enfo, Crayon, Tietoevry), covering cloud infrastructure and cybersecurity from fundamentals through architect-level topics.

---

### Key Skills Developed
- Cryptography, encryption, and network/device threat analysis
- Azure infrastructure: compute, storage, virtual networking, monitoring
- Azure Active Directory and Microsoft Compliance Solutions
- Identity and access management, platform and application security
- Security strategies, resilience, and compliance and risk management
- Cybersecurity architecture and efficient security practice

---

### Practical Components
- Multi-course hands-on labs across Azure environments
- Applied security configurations in identity, network, and data domains
- Architecture-level security planning across all six courses
