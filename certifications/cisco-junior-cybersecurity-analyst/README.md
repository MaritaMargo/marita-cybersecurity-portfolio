# Cisco Junior Cybersecurity Analyst – Career Path

## Overview
Completed the Cisco Networking Academy Junior Cybersecurity Analyst career pathway.

This pathway provides foundational and practical knowledge in networking, security operations, and threat analysis.

## Core Areas Covered
- Networking fundamentals
- Network devices and initial configuration
- Endpoint security
- Network defense
- Cyber threat management
- Security monitoring concepts

## Practical Skills Developed
- Basic router and network configuration (Packet Tracer)
- DHCP and IP addressing
- Wireless security configuration (WPA2)
- Threat awareness and defensive concepts
- Understanding of SOC workflows
- Risk and vulnerability awareness

## Tools & Platforms Used
- Cisco Packet Tracer
- Networking Academy Labs
- Web-based simulations

## Outcome
Built foundational skills aligned with entry-level roles such as:
- Junior Cybersecurity Analyst
- SOC Analyst (entry-level)
- IT Support / Security Support roles
