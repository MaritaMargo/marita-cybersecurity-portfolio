# Blue Team Project – IOC Analysis & Threat Investigation

## Scenario
Investigation of suspicious activity using Indicators of Compromise (IOCs).

## Objectives
- Identify malicious IP addresses and domains
- Analyze suspicious log entries
- Extract indicators from alert data
- Assess potential impact on systems

## Tools & Concepts Used
- IOC analysis
- Log review
- Network traffic inspection
- Basic threat hunting techniques

## Investigation Process
1. Review alert data
2. Extract suspicious IP/domain/process
3. Correlate with additional logs
4. Determine impact
5. Recommend containment actions

## Key Takeaway
Demonstrated structured SOC-style investigation workflow.
